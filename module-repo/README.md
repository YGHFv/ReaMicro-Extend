# 阅微补全计划（ReaMicro Extend）

阅微补全计划（ReaMicro Extend）是一个面向阅微的 LSPosed 扩展模块，用来补全阅微在搜索、在线源、云盘、阅读、文件编辑和字体管理上的一些日常使用能力。

> 本仓库是 LSPosed 模块仓库（[Xposed-Modules-Repo](https://github.com/Xposed-Modules-Repo)）的发布仓库，只放元数据与发行包，不含源码。源码、问题反馈与完整文档见 [YGHFv/ReaMicro-Extend](https://github.com/YGHFv/ReaMicro-Extend)。

## 功能概览

### 在线补全

- 在阅微设置中增加独立的「在线补全」页面，在线源与关联补全源分开管理。
- 支持导入阅读/Legado 书源格式的在线源（默认读剪贴板链接，长按选择单个源文件），每个源可单独启用/停用。
- 阅微首页搜索并发搜索已启用的在线源，结果分组显示为「在线补全-源名」，可展开更多结果。
- 点击在线搜索结果会后台下载并导入阅微：小于 200 章的图书下载完成后一次性导入；大于 200 章先导入前 100 章，后续章节继续后台写入。
- 通知栏显示章节进度并提供取消按钮；下载失败的章节自动重试。导入会生成标准 EPUB 结构（xhtml 逐章写入 + 目录与元数据）。
- 已导入的图书支持在图书菜单中执行「更新章节」，从对应在线源获取目录并追加新增章节。

### 关联补全

- 在阅微原有关联搜索基础上补充更多关联搜索源，结果按「关联补全-源名」显示，可按源启用/停用。
- 恢复图书详情页的关联操作入口：取消关联、重新关联、封面修复。

### WebDAV 与本地书库

- 在阅微云盘体系中补充 WebDAV 入口，支持登录、浏览、导入、下载与备份。
- 优化云盘/本地书库列表展示，支持本地书库索引与搜索刷新、云盘下载取消、导出到本地存储。

### 阅读页增强

- 阅读页自动翻页；导入时做覆盖检查，避免重复导入误覆盖已有图书。
- 全文搜索增强：建立本地索引，搜索结果列表可定位当前项，跳转后注入高亮，并在高亮未渲染到可见页面时自动纠正翻页。
- 对滚动翻页崩溃增加兜底：检测到上次滚动翻页崩溃后自动回退到平移翻页。

### EPUB 文件编辑

- 支持查看和编辑 `xhtml`、`html`、`xml`、`opf`、`ncx`、`css` 等 EPUB 内部文本文件。
- 支持文件内搜索、结果跳转、替换和未保存修改确认；支持预览图片与字体文件、修改封面。
- 支持新增、重命名、删除 EPUB 内部文件，并在文件变化后刷新缓存。

### 字体补全

- 字体库管理，可导入 `ttf` / `otf` 字体；支持设置全局界面字体与宋体、楷体映射。

### 账号与数据

- 支持导出/导入当前账号登录凭证，保存并切换多个账号，导入导出账号数据包。

### 自动任务与后台

- 本地自动任务支持每日轶闻、领奖后祈愿、自动阅读、自动行商和期物典当；配置与执行进度按账号保存。
- 任务通知显示奖励明细并给物品上品质色。
- 可选 KSU 独立执行模式（实验性）。配套 KSU 模块 ZIP 已打进 APK，点「使用 KSU」会先用内置 ZIP 自动安装模块。

### 屏幕方向

- 在阅微设置中增加旋转补全：自动旋转、竖向锁定、横向锁定、反向旋转。

## 安装与使用

1. 下载并安装本模块 APK。
2. 在 LSPosed 中启用模块，并勾选阅微（`app.zhendong.reamicro`）作用域。
3. 强制停止并重新打开阅微。
4. 进入阅微设置，打开「阅微补全计划」相关开关。
5. 如需在线源，进入「在线补全」页面导入并启用在线源。

通知相关功能需要授予模块通知权限。在线补全下载在后台运行，部分系统可能还需要允许后台启动或关闭过度省电限制。

## 兼容性

- 宿主：阅微（`app.zhendong.reamicro`），当前适配 2.3.2 beta（versionCode 2310）。
- 框架：LSPosed，模块以 libxposed API 101 声明（`META-INF/xposed/module.prop`，minApiVersion / targetApiVersion = 101）。
- 系统：Android 8.0（API 26）及以上，targetSdk 35。
