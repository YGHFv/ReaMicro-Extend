# WebDAV 同步扩展

## 使用

- 在阅微「设置 → 补全计划 → 云盘补全」打开「同步扩展」（默认关闭）。
- 在「同步」页的「其他 S3 服务」上方点击「使用 WebDAV」。
- 填写 WebDAV 地址、用户名、密码；匿名服务可留空用户名与密码。
- 点击「验证并启用」。地址应指向现有 WebDAV 根目录，实际同步文件保存在其 `reamicro/` 子目录。
- 配置成功后沿用阅微原生书架同步入口和自动同步；其他设备需安装同一扩展并分别配置。

此功能独立于云盘浏览的 WebDAV 开关和账号，不复用云盘备份目录。启用时替换本机当前 S3 同步配置，不删除原存储的远端文件；切回 S3 需重新配置。关闭「同步扩展」会隐藏入口并暂停标记的 WebDAV 同步，不清空配置。

## 数据与安全

- 复用宿主书架变更、阅读进度、CBOR 清单、分片、墓碑、基线与冲突重试；只替换存储接口传输层。
- 配置保存在宿主本机 DataStore，不调用阅微账号的配置上传接口。原生 S3 编辑页尝试保存标记配置时也被限定为本地保存。
- 使用强 ETag、`If-Match`、`If-None-Match: *` 保护清单并发写入。服务若忽略条件请求或不给出强 ETag，则拒绝启用，不能降级为无条件覆盖。
- 验证只创建随机探测目录与二进制测试对象，随后清理；不读取或更改真实书架。
- 配置弹窗遮蔽密码、禁用自动填充和截图。推荐 HTTPS；HTTP 的 Basic 凭据在传输中没有加密保护。
- 切换同步根时按照原生 Session 保存逻辑清除旧基线。保存失败尝试恢复旧配置及基线，验证失败或取消不保存。
