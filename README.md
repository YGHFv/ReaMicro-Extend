阅微补全计划（ReaMicro Extend）是一个面向阅微的 LSPosed 扩展模块，用来补全阅微在搜索、在线源、云盘、阅读、文件编辑和字体管理上的一些日常使用能力。

- 本项目非「阅微」官方人员开发，一切行为与官方无关，如有侵权，请告知本项目删除或关闭。

- 仅供学习与测试，请在 24 小时内自行删除，不保证稳定性与可用性。

## 功能概览

### 在线补全

- 在阅微设置中增加独立的「在线补全」页面，在线源与关联补全源分开管理。
- 支持导入阅读/Legado 书源格式的在线源：
  - 点击「添加在线源」默认读取剪贴板链接导入。
  - 长按「添加在线源」可选择单个源文件导入。
  - 一次只允许导入一个源，检测到多个源会取消导入。
- 每个在线源可单独启用/停用。需要账号密码的源会弹出登录框；暂不支持登录的源允许跳过后启用。
- 阅微首页搜索会并发搜索已启用的在线源，搜索分组显示为「在线补全-源名」。
- 搜索结果按阅微原有搜索分组方式展示：每个源默认显示首个/最佳结果，可通过列表展开按钮展开更多结果。
- 在线搜索结果展示封面、书名、作者，以及连载状态、字数、章节数、更新时间等可获取信息。
- 点击在线搜索结果会后台下载并导入阅微：
  - 小于 200 章的图书下载完成后一次性导入。
  - 大于 200 章的图书先下载前 100 章并导入书架，后续章节继续后台下载并写入。
  - 下载期间可继续阅读其他图书或切到其他应用。
  - 通知栏显示章节进度，并提供取消按钮；取消或异常中断后会清理临时下载缓存。
  - 下载失败的章节会自动重试，仍失败时跳过继续下载，后续再重试。
- 在线导入会生成标准 EPUB 结构，逐章写入 `xhtml`，生成目录与元数据，并清理正文开头重复章节标题。
- 支持在线源封面下载与显示，包括同源 `http` 封面自动升级为 `https`、必要时放行明文封面请求。
- 在线补全导入的图书支持在图书菜单中执行「更新章节」，从对应在线源获取目录并追加新增章节。

### 关联补全

- 在阅微原有关联搜索基础上补充更多关联搜索源，并按「关联补全-源名」显示结果。
- 支持按源启用/停用关联补全搜索源。
- 恢复图书详情页关联操作入口，支持取消关联、重新关联和封面修复。
- 封面、横幅和关联操作统一使用宿主样式的卡片、动作行和取消图标；修复在线图片输入框在键盘弹出后失焦的问题。

### WebDAV 与本地书库

- 在阅微云盘体系中补充 WebDAV 入口，支持 WebDAV 登录、浏览、导入、下载与备份。
- 原生同步服务列表在 WebDAV 下增加 GitHub，复用阅微配置控件及书架同步、合并流程。填写私有仓库（`所有者/仓库` 或 GitHub 地址）、分支（留空使用默认分支）和具备 Contents 读写或 repo 权限的 Token；仓库须已有提交。Token 通过 Android Keystore 加密保存在本地，单个文件上限 40 MiB，多设备写入通过 GitHub 原子版本条件检测冲突。
- 优化云盘/本地书库列表展示，补充图标、标题和部分状态显示。
- 支持本地书库索引与搜索刷新。
- 支持云盘下载取消，取消后同步清理进行中的任务状态。
- 增加导出到本地存储能力，方便把阅微中的图书导出到本地目录。

### 阅读页增强

- 阅读页自动翻页。
- 导入覆盖检查，避免重复导入时误覆盖已有图书；在线补全的阶段性导入走静默更新。
- 阅读页全文搜索增强：
  - 建立本地索引。
  - 搜索结果列表可定位当前项。
  - 跳转后注入高亮，并在高亮未渲染到可见页面时自动纠正翻页。
- 对 ScrollPager 崩溃增加兜底：检测到上次滚动翻页崩溃后自动回退到平移翻页。
- 补充部分阅读 DOM 渲染兼容处理，降低特定书籍排版异常导致的崩溃概率。

### EPUB 文件编辑

- 增强阅微文件编辑能力，支持在图书内编辑 EPUB 元数据和文件内容。
- 支持查看和编辑 `xhtml`、`html`、`xml`、`opf`、`ncx`、`css` 等文本文件。
- 支持文件内搜索、结果跳转、替换和未保存修改确认。
- 支持预览图片和字体文件。
- 支持修改封面。
- 支持在图片菜单中将图片设置为阅微横图，自动按阅微横图命名规则重命名并刷新缓存。
- 支持新增、重命名、删除 EPUB 内部文件，并在文件变化后刷新缓存。

### 字体补全

- 支持字体库管理，可导入 `ttf` / `otf` 字体文件。
- 支持设置全局界面字体。
- 支持宋体、楷体映射，改善阅读排版中缺字或字体不一致的问题。
- 字体库与阅读排版设置互通。

### 账号与数据

- 支持导出当前账号登录凭证。
- 支持从剪贴板或文件导入凭证。
- 支持保存并切换多个账号。
- 支持导入/导出账号数据包。
- 支持启动时清理部分缓存状态，降低异常中断后的残留影响。

### 自动任务与后台

- 独立 Compose 应用支持每日轶闻、自动祈愿、自动阅读、自动行商和期物典当。通过「任务 → 账号管理」粘贴或导入宿主导出的单账号凭证 / 账号合集，最多保存 50 个账号；每个账号使用独立配置、备注、执行进度和记录。新账号的任务默认关闭，重新导入只更新凭证和昵称，保留已有配置与历史。
- 开启某个账号的任务后，按该账号配置自动执行完整流程，不需要额外的「自动完成」开关。行商等待结算、领取奖励后继续下一趟，旧版关闭值自动兼容；阅读按时间锁和书目配置执行，失败后只补本轮未完成书目；祈愿默认在该账号轶闻领奖后执行，也可开启「自定义时间」，使用 Miuix 时分选择器设置每日执行时间（北京时间）；开启后只按设定时间运行，模式与时间按账号保存，部分失败只继续剩余次数。部分成功后的失败记录与通知也展示已上报时长或已获得物品。
- 账号备注留空时显示昵称，支持从凭证、宿主资料和账号合集读取；缺少昵称的旧账号会在后台补取并保存，资料暂不可用时显示 ID。
- 配置保存、开关和手动执行校验账号状态，删除重导入后的旧弹窗不会覆盖新配置。运行中关闭任务或修改配置会保留已确认进度并停止后续旧请求；单账号凭据损坏与其他账号隔离。Root 同步保留较新进度，较大配置使用分段传输。
- 「账号管理」可删除账号，清除其凭证、任务、记录、待执行请求和通知；重新导入同一账号从默认关闭的任务开始，旧任务回执不能重建或污染新账号。
- 「记录」和「任务」页右上角均可选择全部账号或单个账号。顶部账号、排序、关闭、全选和删除图标按可见轮廓统一大小与对齐。通知显示账号备注、ID、任务和执行阶段；点通知进入对应账号记录。Root 唤醒、联网准备、执行中与完成使用独立的运行状态通知，异常与结果保留在记录中。
- 宿主内嵌任务与独立应用完全分开保存，不同步配置、凭证、开关或历史。宿主每次冷启动仅执行当前登录账号已开启的任务一遍；页面重建、回到前台和模块热重载不会重复执行。整批任务的记录保存后，宿主只弹一次 Toast「自动任务已完成，详情请查看任务记录。」，详情位于宿主的「本地任务 → 任务记录」。未执行任务或批次取消时不弹完成提示。宿主切换账号或关闭补全开关会取消当前批次，不再关联 Root 定时调度。
- 模块应用「配置 → 权限与后台」可开启返回桌面后隐藏后台卡片；隐藏不等于保活或强制停止。
- ROOT增强使用 KernelSU / Magisk / APatch 通用模块。只保留 Root 自动调度；不开启增强时仍可手动处理任务，不存在另一套自动唤醒方式。
- 配套模块位于 APK 的 `assets/module/`。仅安装/更新不会自动开启增强，启停和卸载都需明确确认。
- 「同步任务」会核对应用与模块的执行状态。模块已停用时先等待当前任务结束，再取回进度和记录、校正增强开关；只有重新开启增强才恢复后台任务。无法确认模块状态时保留原模式并显示错误，防止重复执行。
- 期物典当的「禁当期物」列出席物点选锁定，弹窗内可「刷新期物清单」现拉当日期物与背包全量（名字与品质只在服务端，任务没跑过也能列全）；按品质从高到低排列，期物名用游戏内一致的品质色显示；默认跳过祈禳/传承/夺宝要用的消耗品，一项都不锁则不禁止。
- 任务通知直接显示奖励明细并给物品上品质色；自动行商通知带新行商结束时间与新运签效果。
- 配套 Root 1.1.2 / 12 与支持新版调度的模块应用配合时，确认没有待发通知后按下一项任务定时，最长 6 小时复查一次。有待发通知或搭配旧版模块应用时，仍每 15 分钟复查。提前重排的任务可以打断等待。
- Root 唤醒仍受休眠、断网、登录失效和内核策略影响，不保证绝对准点；云端任务仍由 API 服务器执行。
- 配套 Root 模块源码见 [reamicro-automation](module/reamicro-automation/)。

## 使用方式

1. 安装模块 APK。
2. 在 LSPosed 中启用模块，并勾选阅微作用域。
3. 强制停止并重新打开阅微。
4. 进入阅微设置，打开「阅微补全计划」相关开关。
5. 如需在线源，进入「在线补全」页面导入并启用在线源。

通知相关功能需要授予模块通知权限。在线补全下载可以在后台运行，部分系统可能还需要允许模块后台启动或关闭过度省电限制。

## 构建

需要：

- JDK 17
- Android SDK

构建调试版：

```bash
./gradlew :app:assembleDebug
```

构建正式版：

```bash
./gradlew :app:assembleRelease
```

CI 通过 `:app:detektDebug` 检查无用引用与复杂度，使用 Android 变体依赖、Java 类和生成的 BuildConfig 解析源码；报告位于 `app/build/reports/detekt/debug.html` 和 `debug.md`。规则发现仅报告，配置错误和执行失败会使 CI 失败。

CI 分别构建并上传 debug 和 release 包，release 失败会直接报错，不会回退到 debug。
GitHub Release 仅发布 release APK 和配套模块；debug APK 在 Actions 构建产物中单独下载。
CI Release 和 LSPosed 模块仓库发布说明使用触发本次构建的提交标题；手动运行或重跑使用所选提交的标题。标题为空或读取失败时，回退为包含当前版本号、版本代码、提交短 SHA 和产物说明的 CI 构建信息。
debug 始终使用调试签名；未配置正式密钥的 release 输出 `release-unsigned.apk`，签名后才能安装。
GitHub Actions 正式签名需要四个 Secrets：`RELEASE_KEYSTORE_BASE64`、`RELEASE_KEYSTORE_PASSWORD`、`RELEASE_KEY_ALIAS`、`RELEASE_KEY_PASSWORD`。

如果需要本地签名正式版，可通过环境变量或 `signing/reamicro-release-secrets.txt` 配置：

```properties
RELEASE_KEYSTORE_FILE=signing/reamicro-release.jks
RELEASE_KEYSTORE_PASSWORD=...
RELEASE_KEY_ALIAS=...
RELEASE_KEY_PASSWORD=...
```

`local.properties` 需要指向本机 Android SDK，例如：

```properties
sdk.dir=C:/Users/<name>/AppData/Local/Android/Sdk
```

## 代码结构

`app/` 为 Android 模块，`module/` 为配套 Root 模块，`server/` 为 API 服务端；`source-files/` 保存内置书源，`third_party/` 保存第三方编辑器。

界面使用 Miuix `0.9.5-beta01`，固定到上游提交 `6d2554a850b8960e2616c968263ff64beb5ffb03`。
`third_party/miuix/upstream/` 仅保留 Android 实际使用的 common/Android 依赖，未用组件与其他平台源码不纳入项目。
图标裁剪为默认别名与 Regular 字重，保留的路径数据与上游一致；Android 性能配置也删除了未用类的规则。
其余保留的上游源码未修改。
`third_party/miuix/android/` 提供 Android 构建和项目专用的弹窗、导航栏尺寸适配。
版本声明见 `gradle/libs.versions.toml`，源码来源与许可证见 [Miuix NOTICE](third_party/miuix/NOTICE)。

- 宿主通过代码中的语义查询定位。`HostReaderFeatures` 按功能查找阅读器方法，`HostSemanticQueries` 为既有逻辑接口查询描述符；`HostQuerySession` 共用桥接与有上限的当前宿主缓存。
- 源码支持 `2.3.3 / 2330`、`2.3.4 beta / 2330` 和阅微2.3.4RC（`2.3.4 / 2340`）。首次加载和手动热重载都检查包名、版本名和版本号，扫描缓存按实际 DEX 内容区分宿主。
- 两个受支持包名共用正文解析、段落批注和界面适配。旧宿主保留五参数正文解析和原批注构造器。发现页和本地图书菜单按宿主的行布局签名调用，兼容 beta 与 2340 版本的行权重参数差异。
- 模块启动会打印 `hook installed N/M, failed: [...]`，设置页「关于 → 模块自检」
  能看到明细。宿主升级后先看这一行定位掉线的 hook。

### API102 热重载

- 入口为阅微「设置 → 补全计划 → 关于补全 → API102 热重载」，需要框架服务支持 API102。
- 模块更新后不再自动调用框架热重载，也不再通过升级广播后台重试；更新后完全退出并重新打开阅微，让新版模块完成自动扫描。手动热重载入口仍保留，扫描期间不可重载。
- 模块加载时保留当前 APK 与 split APK 的资源句柄。更新后尚未重启宿主时，图书结构和源码编辑器仍可读取与当前代码匹配的资源，首次打开也不会因旧安装路径失效而空白。首次安装此修复后需重启一次阅微；以后更新受此保护，新版代码仍需重启或受支持的手动热重载后生效。
- 已验证阅微正式版 2.3.3 的原地界面恢复，以及 2.3.4 beta 在 Android 14 / LSPosed 2.1.0 上的手动热重载：保留进程、Activity 和窗口，重建根界面后首页补全按钮立即生效；深层页面仍不作为保持承诺。
- 更新模块后使用“重启阅微”触发自动扫描。上述手动热重载实测覆盖正式版和 beta 的启动、书架界面。RC 已验证 DEX 查询与行布局调用，界面热重载仍待实机验证。
- 任务或扫描未结束、外部功能源缺少退出协议，或者本进程使用过尚不能安全卸载的模块编辑器/独立 Compose 面板时，会拒绝热重载。此时使用原“重启阅微”。
- “重启阅微”仍是真正的进程重启，和热重载不是同一个操作；正常重启不显示等待卡片，失败时保留提示。
